# Vinux-AI (Project Tigr)

**Vinux-AI** — это легковесная языковая модель, оптимизированная для работы в условиях крайне ограниченного контекстного окна (64 токена) без потери связности и логики диалога[cite: 3, 4].

## 🚀 Почему это уникально?
Вместо попыток расширить контекстное окно или модифицировать веса модели, проект использует архитектуру **Multi-Pass Iterative Refinement (Итеративное уточнение)**[cite: 3, 4].

* **Двухтактная генерация:** Система выполняет «черновой» проход, а затем автоматически корректирует результат, что позволяет боту выдавать полные фразы там, где другие модели обрываются[cite: 3, 4].
* **Агентная логика:** Бот обладает собственным дерзким характером и встроенной системой динамического управления историей диалога[cite: 3, 4].
* **Эффективность:** Модель работает на CPU, потребляя минимум ресурсов, что делает её идеальной для запуска на любом железе[cite: 3, 4].

## 🛠 Технологии
* **Ядро:** PyTorch (архитектура Transformer)[cite: 3, 4].
* **Память:** Интеллектуальный буфер истории (`chat_history`) с динамическим срезом контекста[cite: 3, 4].
* **Интерфейс:** Кастомный CLI на ANSI-последовательностях[cite: 4].

## 📦 Как запустить
1. Клонируй репозиторий.
2. Установи зависимости: `pip install torch`.
3. Запусти систему: `python main.py`.
